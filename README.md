# Sahyog Frontpage

Sahyog Frontpage is a responsive React concept site that presents a unified parcel-network direction. It frames a possible shared layer for brands and logistics providers through discovery, published protocols, and network coordination.

## What it demonstrates

- A responsive multi-page React interface using client-side routing.
- Clear information architecture for an early product concept.
- Reusable content sections for the network model, concept background, and project context.
- A deliberate distinction between a design concept and live operational coverage data.

## Run locally

Requires Node.js 18 or newer.

```bash
npm ci
npm start
```

## Verify

```bash
npm test -- --watchAll=false
npm run build
```

## Scope

This repository is a frontpage exploration. It does not include live provider integrations, current coverage data, or a production contact workflow.
